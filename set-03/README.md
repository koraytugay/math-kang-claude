# Canadian Math Kangaroo Contest (CMKC) Past Papers & Samples (English Only)

Downloaded from [mathkangaroo.ca - Samples / Resources](https://mathkangaroo.ca/samples/en) via official CDN archives (`docs.mathkangaroo.ca/samples/`).

## Overview

- **Total Papers**: 106 PDFs
- **Language**: English Only
- **Years Covered**: 15 years (2002, 2003, 2007, 2012–2023)
- **Divisions**:
  - Grades 1–2 (45 min, 18 problems)
  - Grades 3–4 (60 min, 24 problems)
  - Grades 5–6 (75 min, 30 problems)
  - Grades 7–8 (75 min, 30 problems)
  - Grades 9–10 (75 min, 30 problems)
  - Grades 11–12 (75 min, 30 problems)
  - Parents Questions (Special practice tests for 2014, 2015, 2016, 2021)

## Folder Structure

- **`by_level/`**:
  - `Grade_01-02/` (12 papers, 2012–2023)
  - `Grade_03-04/` (15 papers, 2002–2023)
  - `Grade_05-06/` (15 papers, 2002–2023)
  - `Grade_07-08/` (15 papers, 2002–2023)
  - `Grade_09-10/` (15 papers, 2002–2023)
  - `Grade_11-12/` (15 papers, 2002–2023)
  - `Parents_Questions/` (4 papers, 2014–2021)
  - `Answer_Keys/` (15 answer key papers)

## File Naming Convention

- `CMKC_{Year}_Grade_{Grades}_English.pdf` (e.g., `CMKC_2023_Grade_01-02_English.pdf`)
- `CMKC_{Year}_Grade_{Grades}_Answers.pdf` (e.g., `CMKC_2002_Grade_03-04_Answers.pdf`)
- `CMKC_{Year}_Parents_Questions_English.pdf` (e.g., `CMKC_2021_Parents_Questions_English.pdf`)
