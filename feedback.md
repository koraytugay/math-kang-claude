# Feedback on generated questions

Write a line when a generated question was wrong, confusing, too easy or too hard.
Use the generator name and variant from the answer key (e.g. `[2002 Q6 · notch]`).
The agent marks items `[x]` when they are addressed.

- [ ] (example) y2002_q06 · pieces_total — too easy with 2 pieces, use 3 more often
