# Kangaroo Math Past Papers & Solutions (2009–2025)

Downloaded from [matematica.pt - Kangaroo Questions](https://www.matematica.pt/en/useful/kangaroo-questions.php).

## Overview

- **Total Papers**: 114 PDFs (70.55 MB)
- **Year Range**: 2009 to 2025
- **Files per Year**:
  - **2009–2013**: 6 papers/year (Ecolier, Benjamin, Kadett, Junior, Student + Solutions)
  - **2014–2025**: 7 papers/year (Felix added for Grades 1–2 + Solutions)

## Folder Structure

The archive provides two directory structures for convenience:

1. **`by_year/`**: Organized chronologically by competition year (all grade levels and answer key together).
2. **`by_level/`**: Organized by student grade level across all available years (linked via hardlinks to save space without creating broken references).

### File Naming Convention

Files are named self-descriptively so they can be identified even if copied outside their folders:
- `Kangaroo_{Year}_Grade_{Grades}_{Name}.pdf` (e.g. `Kangaroo_2024_Grade_03-04_Ecolier.pdf`)
- `Kangaroo_{Year}_Solutions.pdf` (e.g. `Kangaroo_2024_Solutions.pdf`)
